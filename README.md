# Explainable AI-Based Depression Risk Prediction using Lifestyle Factors

## Overview

Mental health disorders, particularly depression, have become a major global concern. Early identification of individuals at risk can help promote timely intervention and improve overall well-being.

This project presents an Explainable AI (XAI) based depression risk prediction system that classifies an individual's mental health risk into **Low Risk**, **Moderate Risk**, or **High Risk** using lifestyle, psychological, work-related, and demographic factors.

Unlike traditional machine learning applications that only provide predictions, this system integrates **SHAP (SHapley Additive Explanations)** to explain which factors contributed the most towards each prediction. The application is deployed using **FastAPI** for the prediction backend and **Streamlit** for an interactive user interface.

# Dataset Features

The model uses **24 input features** categorized into different sections.

### Basic Information

- Age
- Gender
- Marital Status
- Education Level

### Lifestyle

- Sleep Hours
- Physical Activity
- Screen Time
- Social Support Score

### Work & Academic

- Employment Status
- Working Hours
- Work Stress Level
- Academic Pressure Level
- Job Satisfaction Score
- Financial Stress Level

### Psychological Factors

- Anxiety Score
- Depression Score
- Stress Level
- Mood Swings Frequency
- Concentration Difficulty Level

### Clinical History

- Panic Attack History
- Family History of Mental Illness
- Previous Mental Health Diagnosis
- Therapy History
- Substance Use

# Model Performance

The following machine learning models were evaluated.

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 75.04% |
| Decision Tree | 99.10% |
| Random Forest | 96.26% |
| XGBoost | 99.88% |

The final deployed model is **XGBoost** due to its superior performance.

---

# Explainable AI

To improve transparency, the project uses **SHAP (SHapley Additive Explanations)**.

Instead of only predicting the depression risk, the model also explains:

- Which factors influenced the prediction
- Contribution score of each important feature
- Personalized recommendations based on the identified factors

# Installation

Clone the repository

```bash
git clone https://github.com/sohail-m09/Depression_ML.git

cd Depression_ML
```

Install the required packages

```bash
pip install -r requirements.txt
```

---

# Run FastAPI

```bash
uvicorn api.main:app --reload
```

The API will run on

```
http://127.0.0.1:8000
```

Swagger Documentation

```
http://127.0.0.1:8000/docs
```

---

# Run Streamlit

Open another terminal

```bash
cd streamlit

streamlit run app.py
```

The application will open automatically in your browser.
